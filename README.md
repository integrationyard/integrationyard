# Integration Yard

We build reliable Jira integrations and automation — practical tools for teams who live in issue trackers and error dashboards.

**Website:** [integrationyard.com](https://integrationyard.com) · **X:** [@IntegrationYard](https://x.com/IntegrationYard) · **Status:** [status.integrationyard.com](https://status.integrationyard.com) · **Support:** support@integrationyard.com

## What we make

- **[Autoticket for Sentry and Jira](https://integrationyard.com/autoticket/)** — create and two-way sync Jira work items from Sentry issues and alerts (including Sentry Team plan). Guides:
  - [Automatic tickets on Sentry Team](https://integrationyard.com/autoticket/automatic-tickets-on-sentry-team-plan/)
  - [Required custom fields](https://integrationyard.com/autoticket/sentry-jira-required-custom-fields/)
  - [Close Jira when Sentry resolves](https://integrationyard.com/autoticket/close-jira-ticket-when-sentry-issue-resolved/)
  - [vs. Sentry Business](https://integrationyard.com/autoticket/vs-sentry-business/)

## Where we help

We answer real questions (with disclosure when we mention our own apps) about:

- Sentry ↔ Jira linking, alert actions, and plan gates
- Jira Automation + webhooks for error → ticket flows
- Required custom fields, templates, and createmeta gotchas
- Regression / resolve sync between Sentry and Jira
